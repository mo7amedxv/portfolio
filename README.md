## 🚀 Getting Started

```bash
git clone https://github.com/mo7amedxv/portfolio.git
cd portfolio
npm install
```

Build the compiled, minified CSS once:

```bash
npm run build:css
```

Or watch for changes while developing:

```bash
npm run watch:css
```

Then open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```
